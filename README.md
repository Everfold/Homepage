# Everfold Homepage

## Build

```bash
# Installs dependencies
pnpm install

# Local dev
pnpm dev

# Build production
pnpm build

# Preview locally
pnpm preview

# Lint
pnpm lint
pnpm lint:fix

# Format
pnpm format

# Update
pnpm update -L

# AI
npx skills update
```

### Playwright

```bash
# Install Playwright browsers
pnpm exec playwright install

# Install Playwright operating system dependencies
sudo pnpm exec playwright install-deps

# Runs the end-to-end tests.
pnpm test:e2e
```
